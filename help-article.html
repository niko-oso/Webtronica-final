Управление проектами

Раздел: Расширенные возможности

Содержание

    Для перехода к странице Настройки проекта выполните одно из действий:

    • на странице Проекты в плашке нужного проекта (в рабочей области со списком проектов) нажмите на кнопку быстрого перехода к настройкам проекта;
    • выберите нужный Проект в выпадающем списке в шапке личного кабинета и перейдите на страницу Настройки, выбрав соответствующий пункт в меню в левой боковой колонке.

    Страница Настройки проекта содержит следующие вкладки:

    • Общая информация;
    • Регионы и поисковые системы проекта;
    • Управление блоками тегов;
    • Настройки тегирования/анализа страницы.

    Общая информация

    Вкладка Общая информация страницы Настройки проекта предназначена для просмотра и, при необходимости, редактирования следующих данных:

    • Имя проекта;
    • URL проекта;
    • Иконка проекта (favicon вашего сайта, как правило, добавляется в проект автоматически).
    Совет

    Если favicon не определился автоматически, его можно добавить вручную.

    • Дата создания проекта;
    • Последнее обновление проекта;
    • Публичная ссылка для получения тегов проекта.
    Совет для разработчиков

    Код для вставки тегов (см. ниже) позволяет запрашивать теги отдельно для конкретной страницы вашего сайта. Публичная ссылка для получения тегов проекта позволяет получить сразу все теги, сформированные для всего проекта. Так вы повысите быстродействие сайта за счёт меньшего количества запросов к сервису.

    Чтобы Сохранить изменения, внесённые в эти данные, нажмите на соответствующую кнопку. Чтобы Сбросить изменения (это возможно до момента сохранения), нажмите на соответствующую кнопку.

    Кнопка Пример кода для вставки тегов открывает окно Пример кода для вставки тегов на сайт со следующими инструментами:

    • кнопка Копировать код для вставки тегов в буфер обмена;
    • спойлер Открыть код — для просмотра кода для вставки тегов;
    • спойлер Показать пример отдаваемых тегов — для просмотра отдаваемых тегов так, как они будут выглядеть в исходном коде страницы сайта;
    • спойлер Показать пример отдаваемых тегов с тег-блоками — для просмотра отдаваемых тегов, разбитых на блоки, так, как они будут выглядеть в исходном коде страницы сайта.
    Совет

    Инструменты предпросмотра сформированных тегов описаны здесь — см. описание вкладки Тегирование на странице Настройки страницы.

    Регионы и поисковые системы проекта

    Вкладка Регионы и поисковые системы проекта страницы Настройки служит для просмотра и редактирования регионов и поисковых систем, подключённых к проекту.

    Чтобы добавить в проект регионы и поисковые системы:

    1. Перейдите на страницу Настройки проекта.
    2. Откройте вкладку Регионы и поисковые системы проекта.
    3. С помощью выпадающего списка Выбор поисковой системы и кнопки Добавить выберите одну или несколько поисковых систем, в которых вы продвигаете сайт.
      Внимание

      К проекту нужно прикрепить хотя бы одну поисковую систему.

    4. Нажмите на кнопку + Регион в плашке добавленной поисковой системы и выберите в выпадающем списке регион продвижения.
      Внимание

      К каждой поисковой системе нужно прикрепить хотя бы один регион.

    Совет

    Выбранную поисковую систему или отдельный регион можно временно отключить или удалить.

    Управление блоками тегов

    Вкладка Управление блоками тегов страницы Настройки служит для просмотра и настройки правил разбиения тегов на блоки. Блоки позволяют показывать теги на сайте не единым массивом, а отдельными группами в разных частях страницы.

    Совет

    Для уже созданных тег-блоков можно задать дополнительные правила обработки на отдельной странице вашего сайта. При необходимости проконсультируйтесь с разработчиком сайта.

    Чтобы добавить правило разбиения тегов на блоки:

    1. Перейдите на страницу Настройки проекта.
    2. Откройте вкладку Управление блоками тегов.
    3. Нажмите на кнопку Создать новый тег-блок.
    4. Заполните поля формы:
      • Приоритет наполнения блоков (целое число от 1 до 999). Чем меньше значение, тем выше приоритет блока. Например, если созданы два блока с высокочастотными тегами с приоритетами «5» и «10», система сначала заполнит тегами блок с приоритетом «5», а затем, если теги останутся, — блок с приоритетом «10».
      • Наименование блока в коде (только латинские буквы, цифры и нижнее подчёркивание). Это имя станет ключом ассоциативного массива тегов, который приходит от сервиса, и позволит выводить теги в разных частях страницы.
      • Минимальное кол-во тегов в блоке (целое число от 1 до 999). Если для блока, например, высокочастотных тегов указан минимум 5 тегов, а создано всего 3, система добавит 2 тега из блоков с более низкими частотами.
      • Максимальное кол-во тегов в блоке (целое число от 1 до 999). Если указать «0», ограничение на количество тегов в блоке применяться не будет.
      Совет

      Минимальное и максимальное количество тегов настраивайте с учётом вёрстки места, где будет выводиться блок. Например, разумно ограничить размер тег-блока, который отображается в боковой колонке (сайдбаре).

    5. В выпадающем списке Тип тегов в блоке выберите один из вариантов: Высокочастотные, Среднечастотные или Низкочастотные.
      Совет

      Частотность тегов определяется относительно друг друга: в каждом блоке запросы делятся на высоко-, средне- и низкочастотные в соответствии с диапазоном значений, характерным именно для этого блока.

    6. Нажмите на кнопку Создать блок тегов. Новое правило разбиения появится в таблице на вкладке Управление блоками тегов.
    7. Нажмите на кнопку Обновить кэш тегов, чтобы применить новые правила к уже сформированным тегам.
    Совет

    Созданное правило разбиения тегов на блоки можно Удалить. После этого не забудьте снова нажать Обновить кэш тегов.

    Внимание

    После редактирования тегов в вашем аккаунте Webtronica изменения на страницах сайта появляются не сразу — как правило, в течение часа.

    Настройки тегирования и анализа страницы

    Вкладка Настройки тегирования/анализа страницы страницы Настройки служит для просмотра и редактирования общих для всего проекта правил формирования тегов.

    Совет

    Для отдельных страниц сайта можно задать дополнительные правила тегирования. Индивидуальные правила страницы имеют приоритет над общими настройками проекта.

    На вкладке можно настроить следующие параметры.

    Пропускать указанные домены при анализе ТОП-10

    Облако тегов для продвигаемой страницы формируется на основе анализа первых 10 результатов поисковой выдачи («ТОП-10») по соответствующему запросу. Иногда для корректного результата стоит исключить из анализа специфические сайты, попавшие в ТОП-10 и выбранные как ближайшие «конкуренты», — например, сайты поисковиков или агрегаторы.

    Совет

    Часть таких сайтов уже добавлена в список исключений по умолчанию: market.yandex.ru, yandex.ru, 2gis.ru, booking.com, tripadvisor.ru. Удалять их из списка не рекомендуется.

    Чтобы добавить сайт в список исключений, выберите протокол сайта (http или https) в выпадающем списке Запрещённые для анализа ТОП-10 домены, введите домен без протокола и нажмите +.

    Новый домен появится в списке справа. Чтобы удалить сайт из списка, нажмите на крестик в его плашке.

    Запрещённые слова в тегах

    Можно исключить отдельные слова и словосочетания из формирования тегов. Чтобы добавить слово или словосочетание в список исключений, введите его в поле Запрещённые слова в тегах и нажмите +.

    Совет

    Добавьте сюда слова, которые уже есть в интерфейсе сайта — в меню, шапке, футере. Так вы избежите «переспама» этими словами.

    Новое слово появится в списке справа. Чтобы удалить его из списка, нажмите на крестик в его плашке.

    Запрет тегов, ссылающихся на тегируемую страницу

    Чтобы в облаке тегов не было ссылок на ту же страницу, на которой оно выводится, установите флажок При формировании тегов исключить запросы с URL запроса = URL тегируемой страницы.

    Автоматическое перетегирование после сбора позиций

    Флажок Разрешить автоматическое перетегирование страниц после сбора позиций включает или выключает эту функцию для всего проекта.

    Совет

    Не забудьте задать нужные настройки и для каждой отдельной страницы.

    Чтобы Сохранить изменения параметров проекта, нажмите на соответствующую кнопку. Чтобы Сбросить внесённые данные до сохранения, нажмите на соответствующую кнопку.
